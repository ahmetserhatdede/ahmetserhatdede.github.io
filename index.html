September 20, 2026 - Java Printing

Class Notes

In Java, System.out.println() prints text and then moves the cursor to a new line. System.out.print() prints text but keeps the cursor on the same line.

Java Example

This program demonstrates the difference between System.out.print() and System.out.println(). 

public class Printing
{
    public static void main(String[] args)
    {
        // Prints text and moves to the next line
        System.out.println("Hello world.");
        System.out.println("Another line");

        // Prints both parts on the same line
        System.out.print("Print will add to ");
        System.out.print("the same line!");

        // Prints text and then moves to a new line
        System.out.println(" New line after this!");
    }
}

Sample Output

Hello world.
Another line
Print will add to the same line! New line after this!

What I Learned

I learned the difference between print and println in Java. The challenging part was getting used to which command has which function. I solved this by practicing and getting used to using these similar commands.

2.7 - While Loops and Iteration

I learned that iteration means repeating a set of instructions. A while loop repeats its code as long as its Boolean condition remains true. The condition is checked before each iteration. 

int counter = 1;

while (counter <= 5)
{
    System.out.println(counter);
    counter++;
}

This loop prints the numbers from 1 to 5. The counter increases by 1 after each iteration. When counter becomes 6, the condition becomes false, and the loop stops.

I also learned about infinite loops. An infinite loop occurs when its stopping condition never becomes false. We can prevent infinite loops by updating the variables involved in the condition. 

int timeLeft = 10;

while (timeLeft >= 0)
{
    System.out.println("Time remaining: " + timeLeft);
    timeLeft--;
}

I practiced using break and return statements. The break statement immediately exits a loop, while return exits the entire method. These statements are useful when a program needs to stop after a specific event. 

while (true)
{
    int number = (int)(Math.random() * 10);

    if (number == 7)
    {
        break;
    }
}

In exercises such as Taffy Runner and Guess Everest Height, I used while loops to repeatedly collect user input until a required condition was satisfied.

I learned that a for loop combines initialization, a Boolean condition, and an update statement in one header. It is especially useful when the number of iterations is known before the loop begins.

In this example, i starts at 1, the loop continues while i is less than or equal to 5, and i++ increases i by 1. I also practiced changing the increment to count by different amounts or in descending order.

September 21, 2026 - Project: Farmer Ryan

Project Description

In this project, I created a Java program that asks the user for the number of beans in six different bags. The program stores each input in a variable, adds all six values together, and prints the total number of beans Farmer Ryan needs to plant.

Java Code

import java.util.Scanner;

public class FarmerRyan
{
    public static void main(String[] args)
    {
        Scanner input = new Scanner(System.in);

        System.out.print("The amount of beans Nora has taken from the first bag is: ");
        int bag1 = input.nextInt();

        System.out.print("The amount of beans Nora has taken from the second bag is: ");
        int bag2 = input.nextInt();

        System.out.print("The amount of beans Nora has taken from the third bag is: ");
        int bag3 = input.nextInt();

        System.out.print("The amount of beans Nora has taken from the fourth bag is: ");
        int bag4 = input.nextInt();

        System.out.print("The amount of beans Nora has taken from the fifth bag is: ");
        int bag5 = input.nextInt();

        System.out.print("The amount of beans Nora has taken from the sixth bag is: ");
        int bag6 = input.nextInt();

        int total = bag1 + bag2 + bag3 + bag4 + bag5 + bag6;

        System.out.println("Ryan has to plant " + total + " beans");
    }
}

Sample Input

241 675 897 12 4354 7625

Sample Output

Ryan has to plant 13804 beans

What I Learned

I practiced using Scanner to take user input, storing integer values in variables, adding multiple variables together, and printing a result that combines text with a calculated value.
